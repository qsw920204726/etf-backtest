# ETF 场内回测系统

A 股场内 ETF 动量轮动回测：Python 引擎 + akshare 免费日线（后复权）+ Web 报告页。

## 快速开始

**日常使用（无需命令行）**：双击桌面「ETF回测系统」快捷方式（或项目里的 `启动回测系统.bat`），
浏览器自动打开 http://127.0.0.1:8321 —— 改参数点「运行回测」；「更新数据」按钮增量拉最新行情；
顶部「今日操作信号」卡片直接告诉你今天该拿什么/是否调仓。用完关掉最小化的服务窗口即可。

**开发/进阶（命令行）**：
```bash
py run_backtest.py                    # 默认：月末调仓、最强2只、150日风险调整动量
py tests/test_synthetic.py            # 合成数据确定性测试（17项，不依赖网络）
py tests/test_engine.py               # 真实数据冒烟校验（买入持有/T+1/现金守恒）
py sweep.py                           # 参数扫描 + IS/OOS 稳健性验证（约70秒）
py -m uvicorn api.main:app --port 8321   # 手动启动 Web 服务
```

## 结构


## 关键设计（防回测自欺）

- **防未来函数**：信号 T 日收盘算、T+1 开盘成交；策略只允许访问 `close.loc[:date]`。
  有结构测试兜底：篡改 T 之后的所有行情，T 日前净值与交易逐笔不变。
- **双价格口径**：动量信号用后复权价（含分红/份额折算，跨年可比）；成交/估值/股数取整用
  执行价面板 = 后复权价 × 固定系数（锚定最新真实价）——既正确又能和行情软件对上价。
  不能直接用真实价回测：份额合并/拆分会被算成暴跌。
- **三数据源**：东财(hfq/raw) 主源 → 新浪(raw)/腾讯(hfq) 兜底，跨源合并按锚点等比换算；
  系统代理(Clash 等)自动绕行国内数据源；断网时回退本地 parquet 缓存。
- **T+1**：当日买入冻结，日终解冻；卖出只动可用份额。
- **成本**：佣金双边万2.5（默认免5，可配）、可选单边滑点、调仓噪音过滤（单只权重差<2%不动）。
- **空字典信号**：`on_bar` 返回 `{}` = 清仓持币（曾因 `if targets:` 被 falsy 吞掉，已修并有回归测试）。

## 默认参数怎么来的（不是拍脑袋）

轮动池 2026-08 改为科技+创新药导向后，`py sweep.py`（72 组网格）在新池上重新做了
**IS(2015-2020) 选参、OOS(2021-2026) 验证**：

| 结论 | 证据 |
|---|---|
| 科技池偏好短动量+周频 | 20/W 邻域（top1~3、RA 开关）整体是 IS/OOS 双强高原 |
| 风险调整动量（收益/波动）更稳 | OOS 夏普前五名全部是 RA |
| IS 优选组样本外有延续性 | IS Top10 的 OOS 夏普中位数 0.418 vs 全体 0.250 |

**默认参数（20日/W/top3/RA + 溢价过滤3% + 量能加成）全期 2015-01~2026-08 实测**：
年化 19.1%（基准 3.6%），最大回撤 -29.6%（基准 -44%），夏普 0.98，OOS(2021+) 夏普 1.12。
持仓不变的周无交易记录。

**已验证的辅助指标（2026-08 实验，A+C 为默认）**：
| 指标 | 结果 | 决定 |
|---|---|---|
| A 溢价过滤(>3%剔除) | OOS 夏普 1.01→1.09，防 QDII 高溢价接盘 | ✅ 默认开 |
| C 量能加成(20/60日额比) | 年化 +0.4pct，回撤持平 | ✅ 默认开 |
| B 相关性分散(ρ<0.85) | 回撤 -26%→-50%，强制剔相关破坏动量 | ❌ 弃用 |
| 多窗口复合动量(20/60/120) | 年化 18→13.5%，钝化反应 | ❌ 弃用 |
| 波动率倒数加权 | 回撤 -26→-24%，夏普↑ | 可选(vol_inverse) |

**已知诚实声明（务必读）**：
- 年换手约 15 倍是主要风险：实盘请用限价单贴盘口成交，别无脑市价单
- 2026-08 修复过一个 broker 预算分配 bug（最后一只买入恒欠半仓、连周补仓），
  修复使年化 +2.3pct——早期数字（15.7%）为带 bug 口径
- 池子改版后重新扫参存在二阶过拟合风险，靠 20/W 邻域高原 + OOS 延续性缓解，但非免疫
- 科技池同涨同跌性强，动量退化为行业追涨时靠绝对动量过滤（全负→持币）保命
- 2015-06 式急跌周频也只能少挨不能不挨；历史回测不代表未来

## 写自己的策略

继承 `strategies/base.Strategy`，实现 `on_bar(date, portfolio_value)`：
返回 `None` 不动；返回 `{code: weight}` 次日开盘调仓；返回 `{}` 清仓持币。

## 安卓 App（离线回测）

- 安装包：仓库根目录 `ETF回测.apk`（约460KB），传到手机点击安装（需允许"未知来源应用"）
- **完全离线**：内置全部历史数据快照 + JS 移植版引擎（与 Python 版同口径：T+1开盘成交、
  佣金万2.5、100股取整、周频/月频动量、风险调整、绝对动量过滤）
- 功能：今日操作信号（卖出/持有/买入 + 按资金算建议股数）、KPI、净值/回撤图、交易明细
- 联网时点「更新数据」可直接从东财拉最新行情（失败自动回退内置快照）
- 数据快照更新：电脑端跑 `py export_mobile_data.py` 后 `bash app/build_apk.sh` 重新打包

## Web 报告页

`py -m uvicorn api.main:app --port 8321` 后浏览器打开 http://127.0.0.1:8321 —— 
今日操作信号卡片 → 参数表单 → KPI 瓷砖 → 策略/基准净值 → 回撤曲线 → 持仓时间轴（泳道）→ 交易明细表，
支持明暗主题切换、「更新数据」一键增量拉行情。
信号卡片语义：月中不会误报"月末"（数据末月不完整时回退到最近一次真实月末确立的持仓），
周频以周五为调仓日。
